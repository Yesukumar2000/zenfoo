# Project: Zenfo Delivery Partner

## Overview
Flutter delivery partner app for the Zenfoo platform.

## Tech Stack
- Flutter/Dart
- Provider for state management

## Project Structure
- `lib/view/` - UI screens and widgets
- `lib/providers/` - State management (Provider)
- `lib/repository/` - Data/API repositories
- `lib/utils/` - Utilities and constants

## Conventions
- Follow existing code patterns and naming conventions
- Use Provider pattern for state management
- API URLs are defined in `lib/utils/app_urls.dart`

## Commands
- Run: `flutter run`
- Build APK: `flutter build apk`
- Get dependencies: `flutter pub get`
